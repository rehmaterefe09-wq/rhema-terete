RHEMA TEREFE — BEAUTIFUL MOBILE APP VERSION 2

This is a phone-first Progressive Web App (PWA). It can be published on GitHub Pages and installed on Android from Chrome. No Android Studio and no APK are required for this GitHub-hosted version.

PUBLISH TO GITHUB:
1. Extract this ZIP.
2. Upload ALL FOUR files to the ROOT of your public GitHub repository: index.html, manifest.webmanifest, service-worker.js, icon.svg.
3. Commit the files.
4. Open repository Settings > Pages.
5. Choose Deploy from a branch, branch main, folder /(root), then Save.
6. Wait for the published HTTPS website address.

INSTALL ON ANDROID:
1. Open the published HTTPS address in Chrome.
2. Visit once while connected to the internet.
3. Open Chrome menu (three dots) > Install app or Add to Home screen.
4. Tap the Rhema Terefe icon on your home screen.

IMPORTANT HONEST LIMITS:
- This is an installable web app, not a native APK or Play Store app.
- Demo login is not secure authentication.
- Registration and admission forms store sample data only in that browser/device; they do not send anything to Tercha High School.
- Marks, attendance, verified teachers, official school information, messaging and multi-device sync need school authorization and a secure shared backend.
- Use fictional demo data until the school approves the project.
- Offline cache is created after the first successful online visit. Features that require a shared server will need internet.
