RHEMA TEREFE — PHONE-READY GITHUB PAGES WEBSITE

UPLOAD THESE FOUR FILES TO THE ROOT OF YOUR PUBLIC GITHUB REPOSITORY:
- index.html
- manifest.webmanifest
- service-worker.js
- icon.svg

Then open GitHub repository > Settings > Pages.
Choose Deploy from a branch, branch main, folder /(root), then Save.

After GitHub Pages publishes, open the website link on your Android phone in Chrome.
Use Chrome menu (three dots) > Install app or Add to Home screen.

PHONE AND OFFLINE NOTES:
- The layout adapts to phone screens.
- It can be installed to the phone home screen as a web app.
- The service worker caches the site after the first successful visit, so the cached website can reopen offline.
- The first visit and initial cache need internet.
- Sample lessons and quizzes are starter examples.
- AI chat and real student-to-student messaging are not implemented.
